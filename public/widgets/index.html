Hosted intake form previews

Run npm run preview:local from public-widget, then open the links below. That command builds and serves the dist/ folder on port 5175. Do not use npm run dev for these URLs (different port and layout).

Iframe embed (production approach)

Squarespace pages embed an iframe pointing at our hosted form HTML. The links below mimic that: a fake parent page, or the iframe document alone.

  • Carolina — parent page + iframe Like a Squarespace page wrapping the form
  • TrueBridge — parent page + iframe Like a Squarespace page wrapping the form

  • Iframe document only — TrueBridge This URL goes in the iframe src

Legacy same-page script (not iframe)

Optional older embed: a <script src="tb-intake-widget.js"> mounts the form directly on the parent page (no iframe). Use npm run dev and open dev.html on port 5174 to try that — not what we ship to Squarespace.
